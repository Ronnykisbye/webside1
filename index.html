Download materialet

Brug GitHub til hurtigt at hente alle filer ned på din computer.

  1. Åbn projektets GitHub-side, klik på Code og vælg Download ZIP.
  2. Udpak ZIP-arkivet til en mappe, hvor du nemt kan finde filerne igen.
  3. Alternativt kan du klone repoet direkte med Git:
git clone https://github.com/<brugernavn>/<repo-navn>.git
                                                cd <repo-navn>

Tip: Opdater <brugernavn> og <repo-navn> til dit eget repository. Du kan altid hente en ny ZIP-fil, hvis du laver ændringer i GitHub.

Sådan ser du appen

  1. Hent projektet til din computer (fx via Code > Download ZIP eller git clone).
  2. Åbn mappen, og dobbeltklik på index.html for at åbne den direkte i din browser.
  3. Hvis du foretrækker en lokal server, kan du køre python -m http.server 8000 fra projektmappen og besøge http://localhost:8000.
  4. Når siden er indlæst, kan du gennemgå fanerne og teste webservicen nederst.

Tip: Visual Studio Code-brugere kan aktivere udvidelsen Live Server for automatisk genindlæsning ved ændringer.

Sådan prøver du siden

  1. Start i overbliksfanen for at få kontekst om læringsmålene.
  2. Gå derefter systematisk gennem de fire områder, og notér spørgsmål til refleksion.
  3. Afslut med webservice-fanen for at prøve dataeksperimentet med egne input.

Tip: Brug noteværktøj eller udskriftsfunktionen i browseren, hvis du vil gemme dine svar.

Sådan lægger du den på kisbye.eu

  1. Upload projektet til et offentligt GitHub-repository, eller opdater et eksisterende.
  2. Aktivér GitHub Pages under repoets indstillinger (Settings > Pages), og vælg hoved-branchens /root-mappe.
  3. Tilføj en DNS-A-record for kisbye.eu, der peger på GitHub Pages IP-adresserne (185.199.108.153–185.199.111.153), samt en CNAME-record for www.kisbye.eu til yourusername.github.io.
  4. Angiv kisbye.eu i feltet Custom domain i GitHub Pages, og bekræft at DNS’en er udbredt. Siden vil derefter være tilgængelig via dit domæne.

Bemærk: Hvis du foretrækker egen hosting, kan du uploade de statiske filer til en webserver på dit domæne – der kræves ingen backend.

Sådan bruger du siden

  1. Vælg et læringsområde via fanerne for at gennemgå spørgsmål og svar.
  2. Udnyt ressourcerne til at forberede fremlæggelser eller praktiske øvelser.
  3. Prøv webservicen ved at indtaste et navn og analysere de foreslåede lande.

Projektmål

  • Forstå centrale begreber inden for cloud og infrastruktur.
  • Opnå rutine i fejlfinding og anvendelse af forskellige talsystemer.
  • Kunne forklare og håndtere samtidighed i softwareprojekter.
  • Få praktisk erfaring med opsætning og fejlsøgning i netværk.

Sådan tester du siden

  1. Start en lokal webserver (fx python -m http.server 8000) og åbn http://localhost:8000 i en browser.
  2. Bekræft at fanerne vises korrekt, og klik gennem hvert læringsområde for at sikre, at indholdet indlæses.
  3. Scroll til webservice-fanen, indtast et gyldigt navn og kontroller, at resultat-tabellen vises uden fejl.
  4. Åbn browserens udviklerværktøjer og tjek konsollen for fejlmeddelelser, mens du bruger siden.
  5. Hvis du ønsker en hurtig automatisk vurdering, kan du køre Googles Lighthouse (indbygget i Chrome) og gemme rapporten.

Tip: Gentag testen efter ændringer, så du sikrer, at både faner og webservice fortsat fungerer.

Computers hardware

En computers hardware består af de fysiske komponenter, der tilsammen udfører beregninger og håndterer data. Centrale dele inkluderer:

  • CPU (Central Processing Unit) – hjernen i systemet, der udfører instruktioner.
  • RAM (Random Access Memory) – midlertidig hukommelse til aktive programmer og data.
  • Lagring – f.eks. SSD eller HDD, hvor data gemmes permanent.
  • Motherboard – forbinder alle komponenter og sørger for kommunikation imellem dem.
  • Strømforsyning – leverer energi i korrekt spænding til komponenterne.
  • I/O-enheder – tastatur, mus, skærm og andre enheder, der muliggør interaktion.

Azure Cloud og anvendelse

Microsoft Azure er en cloudplatform, der leverer en bred vifte af tjenester såsom virtuelle maskiner, databaser, AI og DevOps-værktøjer. Den kan bruges til:

  • At hoste webapplikationer og API'er med høj oppetid.
  • Skalering af ressourcer efter behov uden store investeringer i hardware.
  • Opsætning af sikre databaser og storage-løsninger.
  • Automatisering af deployments via pipelines og Infrastructure as Code.
  • Analyse af data med tjenester som Azure Synapse og Power BI.

Tip: Start med Azure Portal eller Azure CLI for hurtigt at skabe nye ressourcer til projektet.

Bonus: Undersøg også, hvordan Azure AD kan bruges til identitetshåndtering i dine projekter.

Talsystemer og debugging

Dette område fokuserer på at forstå forskellige talsystemer og på at kunne spore fejl effektivt.

Talsystemer

  • Konverter mellem binære, decimale og hexadecimale værdier.
  • Analyser hvorfor to-komplement bruges til at repræsentere negative tal.
  • Udfør bitvise operationer og forklar deres praktiske anvendelse.

Debugging

  • Opstil en systematisk fejlsøgningsstrategi – reproducér, isolér og løs.
  • Brug breakpoints og logging til at identificere problemer i kodebasen.
  • Dokumentér dine fund, så teamet kan lære af fejlene.

Øvelse: Implementér en simpel konverter i valgfrit programmeringssprog, der kan oversætte mellem de tre vigtigste talsystemer.

Samtidighedsproblematikker

Samtidighed opstår, når flere tråde eller processer kører samtidigt og deler ressourcer. Vigtige begreber:

  • Race conditions – når resultatet afhænger af rækkefølgen af operationer.
  • Deadlocks – to eller flere processer venter på hinanden i en cirkel.
  • Mutual exclusion – princip om, at kun én tråd ad gangen må få adgang til kritiske sektioner.
  • Lock-free algoritmer – datastrukturer, der undgår låsning for høj performance.

Prøv at beskrive, hvordan du ville sikre dataintegritet i et system, hvor flere brugere samtidigt opdaterer den samme databasepost.

Computernetværk

Netværksområdet dækker alt fra protokoller til praktisk opsætning:

  • Forklar forskellen på TCP og UDP og hvornår de bør bruges.
  • Beskriv, hvordan DNS fungerer, og hvorfor caching er vigtigt.
  • Analyser et simpelt netværksdiagram og identificér potentielle flaskehalse.
  • Øv dig i at anvende værktøjer som ping, traceroute og wireshark.

Mini-øvelse: Opsæt et virtuelt netværk i en cloudløsning, og dokumentér hvordan du sikrer trafik mellem subnet.
